# Auto Post Image

[简体中文](README.zh-CN.md)

A WordPress plugin that prepares featured images when you publish a post. Use a text cover, an image already in the post, or a default image. Nothing is generated when visitors open the site.

- Optional **Cover text** field for shorter wording without changing the post title.
- Seven bundled fonts, including Chinese fonts; solid, gradient, or local image backgrounds.
- Batch fill for older posts. Existing manually selected images are left alone.
- Settings in English or Simplified Chinese.

Requires WordPress 5.8+, PHP 7.4+, and GD with FreeType.

## Install

Remove any other automatic featured-image plugin first. Upload the release ZIP under **Plugins → Add Plugin → Upload Plugin**, activate it, then open **Settings → Auto Post Image**. For a text cover, check the server preview before saving. Publish a post without a featured image to try it.
