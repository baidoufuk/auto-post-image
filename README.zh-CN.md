# Auto Post Image

[English](README.md)

WordPress 自动配图插件。在发布文章时生成文字封面，或选用正文图片、默认图片；访客打开网页时不会生成图片。

- 可单独填写「封面文字」，不用修改文章标题。
- 内置七款字体，支持中文；背景可选纯色、渐变或本地图片。
- 可分批为旧文章补图，不覆盖手动设置的特色图片。
- 设置界面支持中文和英文。

需要 WordPress 5.8+、PHP 7.4+，以及带 FreeType 的 GD 扩展。

## 安装

先移除其他自动配图插件，再到 **插件 → 安装插件 → 上传插件** 中选择发布版 ZIP。启用后打开 **设置 → Auto Post Image**。使用文字封面时，先看一下服务器预览，再保存设置。发布一篇没有特色图片的文章即可试用。
